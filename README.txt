JANO — JOHN MERWIN ALVA PORTFOLIO

HOW TO OPEN
1. Extract this ZIP folder.
2. Open the extracted JANO-Portfolio-Final folder in Visual Studio Code.
3. Open index.html.
4. Right-click inside index.html and choose "Open with Live Server".

PROJECT FILES
- index.html: website content and structure
- style.css: responsive black-and-white design, Montserrat typography and glass effects
- script.js: mobile navigation, category carousels and large image viewer
- assets/portfolio-logo.svg: vector portfolio title artwork
- images/about-me.png: transparent About portrait
- images/: apparel portfolio images

PORTFOLIO
The project section displays four category cards:
- Corporate Wear
- Basketball Jersey
- Cycling Jersey
- Performance Wear

Each category has its own image carousel. Use the arrows or dots to browse that category. Click the large image area (or "VIEW LARGE") to open the full-screen image viewer. Use the viewer arrows, keyboard arrow keys, or swipe on a phone to browse images.
